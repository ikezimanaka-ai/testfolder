# quizType

- options
  * It's need some options to choose from.
  - 1 : can only one option. Use "__option1__"
  - 2 : can choose multiple options. Use "__option2__"
  - 3 : can choose multiple options. But it isnt in no particular order. Use "__option3__"

- input
  - text : can input text. Use "__Tinput__"
  - number : can input number. Use "__Ninput__"
