1. 初期からあるJSファイルとその役割

engine.js ui-objects.js docs / studio
  • engine.js: ゲームの起動、Display・GameObject、入力、衝突判定などの基本動作をまとめたコア。
    使うときは import { Engine, Display, GameObject, INPUT, Shapes } from "./engine.js"; のように使う。
  • ui-objects.js: TextObject, ButtonObject, BarObject, SliderObject などのUIオブジェクト。
  • examples/docs/*.html: 実際のコード例、テスト、Monacoエディター、SVGアセット編集用の開発ページ。
  • examples/docs/tutorials/*.html: 機能ごとの使い方とコード例。

GameObjectINPUT配列管理

胴体の数を配列で持ち、蛇の進行と食べ物判定を作る例。

const body = [];
for (let i = 0; i < 100; i++) {
  const part = engine.addObject(world, new GameObject({ shapes: [square("#4ade80")] }));
  body.push(part);
}
