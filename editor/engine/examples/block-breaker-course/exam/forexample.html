Game・Scene・GameObject の関係

Game はゲーム全体の進行係です。Canvas の初期化、毎フレームの更新、現在の Scene の描画を担当します。Scene はその中にいるオブジェクトをまとめる舞台で、GameObject はプレイヤーや敵や弾のような役者です。

流れとしては、まず Game.init() でエンジンを起動し、次に new Scene() で舞台を作り、最後に Game.setScene(scene) でその舞台を現在の場面として渡します。

Game.init("gameCanvas", true, {
    width: 600,
    height: 400,
    backgroundColor: "#050b16"
});

const mainScene = new Scene();
mainScene.add(new Player(80, 200));
Game.setScene(mainScene);

Game の重要プロパティ

関数だけでなく、Game が持っている重要な状態も理解しておくと読みやすくなります。特に currentScene は、ほぼすべてのゲームロジックが間接的に頼っている中心のプロパティです。

  • currentScene: いま更新・描画の対象になっている Scene です。Game.setScene(scene) で差し替えます。GameObject.getCollidingObject() やサンプルの検索処理は、ここを通して Scene 内の他オブジェクトを見ます。
  • dt: 前フレームからの経過秒数です。Game.loop() の中で更新され、速度を秒単位で扱う基準になります。
  • width / height: ゲーム内部の論理解像度です。オブジェクト配置や UI 位置は基本的にこれを基準にします。
  • debugMode: 当たり判定の赤枠を描くかどうかのフラグです。Game.init(..., true) で有効になります。
  • backgroundColor: 毎フレーム背景を塗る色です。
  • canvas / ctx: 実際の描画先 Canvas と 2D 描画コンテキストです。
  • global: Scene をまたいで共有したい値を入れるためのオブジェクトです。

とくに Game.currentScene は、「いまの舞台そのもの」を指します。サンプルではプレイヤーやボスが Game.currentScene.objects を検索して他の相手を見つけ、Game.currentScene.vars を更新してスコアや演出状態を共有しています。

Game 側の最初の API

GameEngine.constructor()

Game は内部的に new GameEngine() で1回だけ作られます。このコンストラクタでは、Canvas の参照、現在 Scene、論理解像度、描画ループの状態、拡大率、背景色など、ゲーム全体で使う土台の値を初期化します。

  • 引数: なし。
  • 主な初期値: canvas = null、currentScene = null、width = 600、height = 400、debugMode = false。
  • 使い方: ユーザーが直接呼ぶ関数ではなく、内部で最初に1回だけ使われます。

Game.init(canvasId, debug = false, options = {})

このエンジンを実際に起動するための入口です。Canvas を探し、2D コンテキストを取得し、入力管理を初期化し、リサイズ監視を設定し、最後に描画ループを開始します。

  • canvasId: HTML 上の <canvas> の id を文字列で渡します。例: "gameCanvas"。
  • debug: true ならデバッグモードで起動します。GameObject.draw() の標準処理を使うと当たり判定枠が見えます。
  • options: 起動オプションをまとめたオブジェクトです。指定しない項目は既定値を使います。
  • options.width: ゲーム内部の論理解像度の横幅です。省略時は現在の Game.width を使います。
  • options.height: ゲーム内部の論理解像度の縦幅です。省略時は現在の Game.height を使います。
  • options.backgroundColor: 毎フレームの背景塗りつぶし色です。省略時は現在の背景色を使います。
  • 戻り値: なし。

この関数を呼ぶと、以前のループが残っていれば最初に stop() で止めてから起動し直します。再実行ボタンが作りやすいのはこのためです。

Game.setScene(scene)

いま描画と更新の対象にする Scene を設定します。以後の毎フレーム処理では、この Scene の update(dt) と draw(ctx) が呼ばれます。

  • scene: 現在の場面として使いたい Scene インスタンスを渡します。
  • 戻り値: なし。

タイトル画面から本編、ゲームオーバー画面からリトライ、といった場面切り替えもこの関数で行います。
