ゲームエンジン詳細ドキュメント

Canvas 2Dで描画し、論理座標・図形ベースの当たり判定・UI Objectを提供する依存パッケージなしのブラウザ用エンジンです。

1. 全体構造と実行モデル

ゲームは Engine → Display → GameObject の3階層です。EngineはCanvas 2D描画とフレーム時計、Displayは描画範囲とclip、GameObjectは形状・当たり判定・ゲームロジックを持ちます。

Engine {
  logicalWidth, logicalHeight, dt
  displays: [
    Display { x, y, width, height, objects: [
      GameObject { x, y, shapes, tags }
    ] }
  ]
}

座標はCSSピクセルではなく理論座標です。たとえば理論サイズを800×450にすると、Canvasが400×225でも1600×900でも同じゲーム範囲が縦横比を保って表示されます。余った部分はcontain表示の余白になります。

Displayの更新は範囲外でも続きますが、描画はDisplayの幅・高さでclipされます。Canvas全体は理論サイズを基準にcontain表示されます。

2. Engine

生成と開始

const engine = new Engine(canvas, 60, 800, 450);
const world = engine.newDisplay(new Display("world", 800, 450));
engine.start();
// 停止: engine.stop()
API引数 / 戻り値役割
new Engine(canvas, fps, width, height)Canvas要素、目標FPS、理論幅、高さ / EngineCanvas 2Dと論理座標系を初期化します。requestAnimationFrameで更新・描画します。
engine.newDisplay(display, x, y)Display、論理x/y / DisplayDisplayを追加順に重ねます。x/yを省略するとDisplayの値を使います。
engine.addObject(display, object, overrides)登録済みDisplay、GameObjectまたは定義、上書き値 / GameObjectObjectをDisplayの最前面へ追加します。
display.bringToFront(object) / sendToBack(object)Display内のObject描画順とCanvas上のポインター選択順を変更します。
engine.dt秒数 / number直前フレームからの経過時間。異常な長時間停止時は最大0.25秒に制限されます。
engine.start() / stop()なし開始時にonStartを実行し、以後毎フレーム更新します。二重startは無視します。
engine.loadImage(url) / loadSVG(url)URL / Promise<Image>画像またはSVGをURLから読み込みます。
engine.loadFont(family, url)フォント名、URL / Promise<FontFace>URLのWebフォントを登録します。
engine.setDebug(options)hitboxes / displays / fps当たり判定、Display境界、FPSをCanvasへ表示します。

3. Display

Displayは論理座標上のCanvasレイヤーです。背景を持たせる場合はObjectより先に塗られ、描画はDisplayの矩形内にclipされます。

const hud = new Display("hud", 300, 100, {
  x: 20, y: 20,
  background: "rgba(0, 0, 0, .5)",
  onStart() { console.log("一度だけ"); },
  onUpdate(dt) { /* 毎フレーム */ }
});
engine.newDisplay(hud);

onStartのthisはDisplay、onUpdateのthisもDisplayです。Display内のObjectにはthis.objectsでアクセスできます。

背景画像はImageObjectをDisplayの先頭に追加するか、GameObjectとして描画します。

4. GameObject

定義型と継承

class Enemy extends GameObject {
  constructor(overrides = {}) {
    super({ x: 100, y: 100, tags: ["enemy"], shapes: [makeCircle()] }, overrides);
  }
  onStart(engine) { /* 初回 */ }
  onUpdate(dt, engine) {
    this.moveX(40 * dt);
  }
}
const enemy = engine.addObject(world, new Enemy({ x: 240 }));
プロパティ / API詳細
x, yDisplay内の論理位置。
rotation, skewX, skewY度数法の回転角と傾斜角。
scaleX, scaleY拡大率。1が等倍。描画と判定へ反映されます。
opacity0〜1を推奨する透明度。
mosaic真の場合にCanvasを低解像度へ描いてモザイク化します。
shapesCanvas形状Descriptorの配列。円・楕円・矩形・線・多角形・文字を指定できます。既存のSVGElementも利用できます。
collisionShapes描画形状とは別に判定形状を設定できます。未指定ならshapesを使います。
onDraw(ctx, dt, engine)Canvas 2D contextで独自描画を追加します。
setPrivate(key, value) / SetPrivateObjectの非公開Mapに値を保存します。getPrivateで読み出せます。
moveX(n), moveY(n)各軸へ相対移動し、thisを返します。
moveTo(x, y)絶対位置へ移動し、thisを返します。
move(x, y)x/yの相対移動。
GameObject.fromAngleDistance(angle, distance)角度を度数法で受け、{x, y}の移動量を返します。0度は右、90度は下方向です。
offsetFromAngle(angle, distance)角度と距離でObject自身を相対移動します。

5. キーボード入力 INPUT

Engineから独立した共有入力状態です。キーイベントはwindowで購読します。入力フォーカスがiframeや別ウィンドウに移った場合、blur時に押下状態をクリアします。

import { INPUT } from "./engine.js";
onUpdate(dt) {
  if (INPUT.onKey("ArrowLeft")) this.moveX(-200 * dt);
  if (INPUT.pressed("Space")) this.jump();
  if (INPUT.released("Space")) this.stopJump();
}
API判定タイミング例
INPUT.onKey(keyid)押されている全フレーム"ArrowLeft", "Space", "a", "KeyA"
INPUT.pressed(keyid)keydownが発生したフレーム一回だけのジャンプ開始
INPUT.released(keyid)keyupが発生したフレームチャージ攻撃の解放
INPUT.pointer.x/y論理座標 / number最後に受けたポインター位置。
INPUT.pointerDown() / pointerPressed() / pointerReleased()押下中 / 押下開始 / 解放フレームCanvas上のマウス・タッチ入力を調べます。
ブラウザの予約キーやIME入力はOS・ブラウザの影響を受けます。ゲーム操作には矢印キー、Space、英数字のcodeを推奨します。

6. タグ検索と接触判定

const targets = player.getObject("enemy");
const allTagged = player.getObject(["enemy", "active"]);
const touching = player.touching("enemy");
if (player.touchTag("enemy")) { /* 接触中 */ }

getObjectは同じDisplay内のObjectだけを対象にします。配列を渡すと、指定した全タグを持つObjectを返します。自分自身は接触結果から除外されます。

矩形・多角形などの判定は変換済み頂点を使ったSAT、円・楕円は多角形近似で行います。複数形状のうち一組でも重なれば接触です。回転・拡縮・skewも判定へ反映されます。SVG pathと外部SVG画像は矩形近似です。

player.touching({
  tags: ["enemy", "active"],
  x: { min: 0, max: 700 },
  where: { faction: "hostile" }
});
player.setPrivate("faction", "player");

7. 標準UI Objectと継承

ui-objects.jsには、よく使う見た目を持った派生クラスがあります。通常のGameObjectと同じようにengine.addObjectで追加でき、プロパティを変更してからさらに継承できます。

import { TextObject, BarObject, ButtonObject, SliderObject, TextInputObject } from "./ui-objects.js";

const title = engine.addObject(display, new TextObject("タイトル", {
  x: 40, y: 60, fontSize: 32, color: "#ffffff"
}));
const hp = engine.addObject(display, new BarObject({
  x: 40, y: 90, width: 240, value: .75, fill: "#22c55e"
}));
const start = engine.addObject(display, new ButtonObject("開始", {
  x: 40, y: 140, shadow: true, hoverScale: 1.05
}));
start.onClick = () => console.log("clicked");
const volume = engine.addObject(display, new SliderObject({
  x: 40, y: 220, min: 0, max: 100, step: 5, value: 65,
  onChange(value) { console.log("volume", value); }
}));
const name = engine.addObject(display, new TextInputObject({
  x: 40, y: 270, placeholder: "名前を入力"
}));
await engine.loadFont("GameFont", "https://example.com/game.woff2");
クラス主なプロパティ動作
TextObjecttext, fontSize, fontFamily, color, anchorCanvas文字を表示します。URLフォントはengine.loadFontで読み込みます。
BarObjectwidth, height, value, fill, background, radiusvalueを0〜1に制限して、背景と進捗矩形を表示します。
ButtonObjectlabel, shadow, background, hoverBackground, pressedBackground, hoverScale, hoverLift, onClickpointerenter/leave/down/upを使い、hover補間、押下色、クリックコールバックを提供します。影はshadow: falseで消せます。
SliderObjectmin, max, step, value, onChangeCanvas上でドラッグして数値を変更できます。
TextInputObject / NumberInputObjectvalue, placeholder, onInput, onChangeCanvasに見た目を描き、文字入力にはフォーカス表示のない非表示HTML入力を内部利用します。file inputは使いません。
RectObject, CircleObject, EllipseObject, LineObject, PolygonObject形状サイズとstyleCanvas図形をGameObjectとして追加できます。
ImageObject / SpriteAnimationObjectURL、サイズ、フレーム時間画像・SVG URL、複数画像のアニメーションを表示します。

実際の見た目と操作はObject実例ギャラリーで確認できます。影あり、影なし、色変化、拡大、浮き上がり、縮小、押下色の例を切り替えられます。

8. コードエディター

機能別テストページは既成テスト専用です。自由にEngineコードを書き換えて試す場合は、Monaco Editorを備えたコードエディターページ、またはCanvasプレビュー・SVGアセット編集・Object一覧・診断を備えたGame Engine Studioを利用してください。Studioを例で学びたい場合は、2つずつの編集・実行例がある使い方実例集から順に進められます。

ES Moduleを使うため、file://直開きではなく静的サーバーを使います。外部CDNからMonacoを読み込むため、初回表示時はネットワーク接続が必要です。
