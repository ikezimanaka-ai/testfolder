Canvas Engine Studio 実例集

章ごとの短いサンプルをMonacoで編集し、隣のCanvasですぐ実行できます。編集内容はこのブラウザーに章・例ごとに保存されます。

ゲームObjectをCanvas上へ直接配置するチュートリアルではなく、コードとSVGアセットを使ってゲームを作る方法を順に学びます。

進め方

  1. 章を選び、説明を読んでから最初の例を実行します。
  2. Monacoのコードを変更して「実行」を押し、Canvasの結果を比べます。
  3. 2つの例の違いを試し、値や処理を少しずつ変更します。
  4. 最後に章の課題に取り組み、前後の章を組み合わせます。

例は独立した小さなプログラムです。各プレビューを実行すると、その例専用の隔離フレームでゲームが再起動します。プレビューのキー操作を試す前に、一度Canvasをクリックしてください。
