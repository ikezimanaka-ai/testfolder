へびゲーム：コードの読み方

ゲームで遊ぶ

へびは100個の表示Objectを先に作り、論理的なマス座標を配列で管理します。一定時間ごとに先頭を進め、壁または自分に当たると初期形へ戻ります。

準備と座標

import { Engine, Display, GameObject, INPUT } from "./engine.js";
import { TextObject } from "./ui-objects.js";

Engine/Displayは画面と更新、GameObjectはへびの各マス、INPUTはキー、TextObjectはスコア表示に使います。

const NS = "http://www.w3.org/2000/svg";
const square = (fill) => { const e = document.createElementNS(NS, "rect");

squareは色を受け取り、SVGのrectを作る関数です。

Object.entries({ x: -9, y: -9, width: 18, height: 18, rx: 4, fill })
  .forEach(([k, v]) => e.setAttribute(k, v)); return e; };

18pxの角丸マスをObjectの中心に置くためx/yを-9にし、属性を設定して返します。

const engine = new Engine(document.querySelector("#game"), 60, 800, 450);
const world = engine.newDisplay(new Display("snake", 800, 450, { background: "#052e2b" }));

800×450のゲーム面を作ります。

const body = [], grid = 18, cols = 40, rows = 22;
let direction = { x: 1, y: 0 }, next = direction;

bodyは表示Object配列、gridは1マス18px、cols/rowsは40列22行です。directionは現在の移動方向、nextは次の移動方向です。

let food = { x: 25, y: 10 }, timer = 0, score = 0;
const positions = [{ x: 10, y: 10 }, { x: 9, y: 10 }, { x: 8, y: 10 }];

食べ物のマス、経過時間、得点を保存します。positionsは先頭を0番目とするへびの論理座標配列です。

for (let i = 0; i < 100; i++) {
  const part = engine.addObject(world, new GameObject({ x: -100, y: -100, shapes: [square("#4ade80")] }));

最大100マス分のGameObjectを作り、最初は画面外へ置きます。必要な長さだけ後で表示します。

body.push(part); }
const foodObject = engine.addObject(world, new GameObject({ shapes: [square("#fb7185")] }));

各マスをbodyへ保存し、食べ物用の表示Objectを1つ作ります。

入力と食べ物

function placeFood() {
  food = { x: 2 + Math.floor(Math.random() * (cols - 4)), y: 2 + Math.floor(Math.random() * (rows - 4)) };

食べ物を壁から2マス以上離れた範囲にランダム配置します。この関数は食べられたときだけ呼びます。

world.onUpdate = (dt) => {
  if (INPUT.pressed("ArrowUp") && direction.y === 0) next = { x: 0, y: -1 };

world更新は毎フレーム実行されます。pressedは押した瞬間だけtrueです。現在が左右（Y方向0）のときだけ上下へ曲がれます。

if (INPUT.pressed("ArrowDown") && direction.y === 0) next = { x: 0, y: 1 };
if (INPUT.pressed("ArrowLeft") && direction.x === 0) next = { x: -1, y: 0 };

下入力も同じ軸条件で受け付け、左は現在が上下（X方向0）のときだけ受け付けます。これで即座の180度反転を防ぎます。

if (INPUT.pressed("ArrowRight") && direction.x === 0) next = { x: 1, y: 0 };
timer += dt; if (timer < .13) return;

右入力を保存し、timerへ秒数を足します。0.13秒未満ならこのフレームの移動をせずreturnします。

1マス移動と衝突

timer = 0; direction = next;
const head = { x: positions[0].x + direction.x, y: positions[0].y + direction.y };

移動時刻をリセットし、次の方向を現在方向にします。先頭座標へ方向の1を足して、新しいheadを計算します。

if (head.x < 1 || head.x >= cols - 1 || head.y < 1 || head.y >= rows - 1
 || positions.some((p) => p.x === head.x && p.y === head.y)) {

1未満または末端以上なら壁です。someはpositionsのどれかがheadと同じか調べるため、自分の体への衝突も判定できます。

positions.splice(0, positions.length, { x: 10, y: 10 }, { x: 9, y: 10 }, { x: 8, y: 10 });
direction = { x: 1, y: 0 }; next = direction; score = 0;

衝突時は配列全体を初期3マスへ置き換え、右向きに戻し、スコアを0にします。ゲームオーバー画面はなく、即座に再挑戦となります。

} else {
  positions.unshift(head);

衝突しなければ新しいheadを配列の先頭へ追加します。配列の0番目が常に頭です。

if (head.x === food.x && head.y === food.y) {
  score++; placeFood();

headと食べ物が同じマスなら得点を1増やし、食べ物を新しい場所へ移します。ここでは末尾を削除しないため、体が1マス伸びます。

} else positions.pop();
}

食べていない通常移動では末尾を削除します。先頭追加と末尾削除の組み合わせで、配列全体が1マス進みます。

論理座標を画面へ反映

body.forEach((part, i) => {
  const p = positions[i]; part.opacity = p ? 1 : 0;

表示Objectと座標配列を同じ添字で対応させます。座標があるマスだけ表示し、長さを超えたObjectは透明にします。

if (p) part.moveTo(p.x * grid, p.y * grid);
});

論理マスをgrid倍してSVGのピクセル座標へ変換し、各マスを移動します。

foodObject.moveTo(food.x * grid, food.y * grid);
status.text = `スコア: ${score}　（矢印キー）`;

食べ物も同じ変換で表示し、毎回スコア文字を更新します。

engine.start();

EngineがrequestAnimationFrameで更新を開始します。入力は毎フレーム確認されますが、へびの実移動はtimerが0.13秒以上になったときだけです。
