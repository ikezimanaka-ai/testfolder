攻撃パターン：コードの読み方

ゲームで遊ぶ

このゲームは、弾幕でよく使われる規則的な攻撃を順番に避けます。放射、螺旋、狙い撃ち、波、輪と隙間、回転十字、ビーム、雨に加え、曲線、交互の壁、狙い撃ち連射、遅延リング、左右スイープも4.5秒ごとに切り替えます。

const patterns = ["放射", "螺旋", "狙い撃ち", "波",
  "輪と隙間", "回転十字", "ビーム", "雨"];

弾幕名を配列にします。番号で現在のパターンを選ぶため、配列の順序がゲームの進行順になります。一般的な数学パターンを使っており、特定作品の素材やコードをコピーしていません。

if (patternClock >= 4.5) {
  patternIndex = (patternIndex + 1) % patterns.length;
}

4.5秒たつと番号を1増やします。%は余りなので、最後の番号の次は0へ戻ります。これで8種類を繰り返せます。

弾幕はランダムな点を増やすだけではありません。放射は円、螺旋は角度の変化、狙い撃ちはプレイヤー方向、輪は安全な隙間、波は上下の揺れ、ビームは長い危険区域というように、見て避けられる規則を組み合わせます。

追加された弾幕

function curved() {
  for (let i = 0; i < 7; i++)
    addBullet(80 + i * 105, -8, Math.PI / 2, 100, "#f0abfc",
      { wave: true, phase: i, angularVelocity: .18 });
}

曲線はwaveで上下に揺れ、angularVelocityで進行方向を少し回します。同じ速度でも位相phaseが違うため、7発が同じ線ではなく曲がった列になります。

const fromLeft = patternStep % 2 === 0;
if (fromLeft && i === 5 || !fromLeft && i === 1) continue;

交互の壁は左、右、左、右から発生します。1つだけ弾を抜いて隙間を作るため、プレイヤーは壁の隙間へ移動します。

for (let i = 0; i < 3; i++) {
  scheduled.push({ delay: i * .18,
    run() { addBullet(400, 180, base, 170, "#fda4af"); } });
}

狙い撃ち連射は、同じ方向へ0.18秒ずつ遅れて3発出します。scheduledを使うと、1回のパターン関数から時間差のある攻撃を作れます。

scheduled.push({ delay: .45, run() {
  radialBurst(20, gap);
}});

遅延リングは、予告なしで少し待ってから輪を出す練習用です。大きい攻撃にする場合は、ビームと同じようにwarning Objectを先に出すと公平になります。

const angle = fromLeft ? -.45 + i * .08 :
  Math.PI + .45 - i * .08;
addBullet(fromLeft ? -8 : WIDTH + 8, 80 + i * 24, angle, 135);

左右スイープは、端から角度を少しずつ変えた12発を一度に出します。扇形に進むので、単純な横移動より広い範囲を覆います。

低速移動

const speed = INPUT.onKey("Shift") ||
  INPUT.onKey("KeyX") ? 105 : 260;

ShiftまたはXを押している間だけ速度を105にします。押していない通常速度は260です。?:は条件がtrueなら左の値、falseなら右の値を選ぶ短いifです。

if (INPUT.onKey("ArrowLeft")) this.moveX(-speed * dt);
if (INPUT.onKey("ArrowRight")) this.moveX(speed * dt);

上下左右すべてで同じspeedを使うため、低速中は細かな位置調整ができます。弾幕の隙間へ入るときに低速を使う設計です。

後半の複合弾幕

if (elapsed >= 18) {
  const savedIndex = patternIndex;
  patternIndex = (patternIndex + 3) % patterns.length;

18秒後は通常の弾幕を出したあと、3つ先の別パターンも選びます。先に現在の番号を保存するのは、2つ目を出したあと元の表示番号へ戻すためです。

spawnPattern();
patternIndex = savedIndex;
}

同じ発生タイミングで別の弾幕も生成するため、放射と波、螺旋と雨のような組み合わせになります。画面右上には「+ 複合」と表示され、単独パターンではないことが分かります。

大きな攻撃の予告

const warning = engine.addObject(world, new GameObject({
  x, y: 48, shapes: [shape("path", { d: "M -14 0 L 0 -18 L 14 0 Z" })]
}));

ビームをすぐに出さず、発生位置の上側に黄色い三角形を置きます。プレイヤーはこの印を見て、ビームが落ちてくる場所を先に知ることができます。

scheduled.push({
  delay: .65,
  run() { warning.opacity = 0; /* beamを生成 */ }
});

scheduled配列に「0.65秒後に実行する処理」を保存します。毎フレームdelayを減らし、0以下になったら予告を消してビームを出します。

for (let i = scheduled.length - 1; i >= 0; i--) {
  scheduled[i].delay -= dt;
  if (scheduled[i].delay <= 0) scheduled[i].run();
}

後ろから配列を調べるのは、期限切れの要素を削除しても未処理の番号がずれにくくするためです。dtを使うので、フレーム数ではなく秒で予告時間を測れます。

大きなビームを突然出すと、プレイヤーが避ける時間を失います。予告を先に見せることで、難しくても「見て判断できる」攻撃になります。今後は警告の点滅、危険区域の線、左右の安全色表示なども同じscheduled方式で追加できます。

図形とクラス

import { Engine, Display, GameObject, INPUT } from "./engine.js";
import { TextObject } from "./ui-objects.js";

EngineとDisplay、動く物の基底GameObject、入力管理INPUT、文字表示TextObjectを読み込みます。

const NS = "http://www.w3.org/2000/svg";
const square = (fill) => {

SVG名前空間をNSに保存し、色fillを受け取って正方形を作る関数を定義しています。

const e = document.createElementNS(NS, "rect");
Object.entries({ x: -9, y: -9, width: 18, height: 18, rx: 4, fill }).forEach(([k, v]) => e.setAttribute(k, v));

18×18、角丸4のSVG rectを作ります。Object.entriesで属性を順番に設定し、中心がObjectの座標になるようx/yを-9にしています。

class Player extends GameObject {
  constructor(o) { super({ shapes: [shape("circle", { r: 13 })] }, o); }

Playerは半径13の円です（このコードのshapeは同じファイル冒頭のSVG要素作成関数です）。oで初期位置を渡します。

onUpdate(dt) {
  if (INPUT.onKey("ArrowLeft")) this.moveX(-230 * dt);

毎フレーム、押している間だけ左へ移動します。dtを掛けるのでフレーム数ではなく秒あたりの速度になります。

if (INPUT.onKey("ArrowRight")) this.moveX(230 * dt);
if (INPUT.onKey("ArrowUp")) this.moveY(-230 * dt);

右はX増加、上はSVG座標でY減少です。

if (INPUT.onKey("ArrowDown")) this.moveY(230 * dt);
this.x = Math.max(15, Math.min(785, this.x));

下へ動かし、Xを15〜785に制限します。

this.y = Math.max(15, Math.min(435, this.y));
}}

Yも15〜435に制限するため、プレイヤーは画面外へ出ません。

class Bullet extends GameObject {
  constructor(overrides = {}) {
    super({ radius: 6, shapes: [shape("circle", { r: 6 })] }, overrides);

Bulletは弾の基底Objectです。radiusは衝突半径として使い、速度やビームなどの追加値はoverridesで受け取ります。

onUpdate(dt) {
  this.move(this.vx * dt, this.vy * dt);

弾は初期化時のvx（X速度）とvy（Y速度）で移動します。moveは現在座標へ差分を足します。

if (this.wave) this.vy +=
  Math.sin(this.age * 5 + this.phase) * 10 * dt;
this.move(this.vx * dt, this.vy * dt);

waveがtrueの弾はsinで上下速度を少し変えます。angularVelocityを持つ弾は速度ベクトルの角度も毎フレーム回転します。

if (this.x < -50 || this.x > WIDTH + 50 ||
  this.y < -50 || this.y > HEIGHT + 50 || this.age > 12)
  this.opacity = 0;

画面から十分離れた弾、または12秒を超えた弾を透明にします。配列から削除せず、opacityが0の弾を判定から除外する方式です。

初期状態と弾の出現

const engine = new Engine(document.querySelector("#game"), 60, 800, 450);
const world = engine.newDisplay(new Display("dodge", 800, 450, { background: "#3f1d4a" }));

800×450のゲーム面を作ります。Engineのフレーム更新がDisplayと各Objectを更新します。

const status = engine.addObject(world, new TextObject("", { x: 20, y: 27 }));
const patternView = engine.addObject(world,
  new TextObject("", { x: WIDTH - 20, y: 27, anchor: "end" }));

左上にスコアと残機、右上に現在の弾幕名を表示します。どちらもCanvas内のTextObjectです。

const bullets = [];
const warnings = [];
const scheduled = [];

bulletsは飛んでいる弾、warningsは予告表示、scheduledは少し後に実行する攻撃を保存する配列です。

world.onUpdate = (dt) => {
  const elapsed = (performance.now() - started) / 1000;

worldの更新関数は毎フレーム呼ばれます。現在時刻との差を1000で割り、elapsedを秒にします。

function spawnPattern() {
  const name = patterns[patternIndex];
  if (name === "放射") radialBurst(20);

現在の名前に対応する関数を呼びます。関数を分けることで、放射だけ、螺旋だけの計算を独立して読めます。

const interval = patternIndex === 1 ||
  patternIndex === 5 ? .12 : .55;
if (spawnClock >= interval) spawnPattern();

螺旋と回転十字は短い間隔で発生させ、それ以外は少し間隔を空けます。spawnClockをdtで増やし、一定値を超えたときだけ発生します。

b.element.setAttribute("fill", "#f8fafc");
bullets.push(b); }

弾の色を設定し、配列へ保存します。配列をfor...ofで後から調べられるようにする処理です。

後半の複合弾幕

if (elapsed >= 18) {
  const savedIndex = patternIndex;
  patternIndex = (patternIndex + 3) % patterns.length;

18秒後は通常のパターンに加えて、3つ先のパターンも選びます。保存した番号は、2つ目を発生させた後に表示を元へ戻すために使います。

spawnPattern();
patternIndex = savedIndex;
}

同じタイミングで2つの弾幕を発生させます。例えば放射と雨、螺旋とビームが同時に出るため、後半は安全な場所を早く見つける必要があります。

予告と大きな当たり判定

const warning = engine.addObject(world, new GameObject({
  x, y: 48, shapes: [shape("path", { d: "M -14 0 L 0 -18 L 14 0 Z" })]
}));

ビームをすぐに出さず、発生するx位置の上側へ黄色い三角形を置きます。見た目が大きく、避ける時間が必要な攻撃ほど、先に位置を知らせます。

scheduled.push({ delay: .65, run() {
  warning.opacity = 0;
  /* ここでビームを生成 */
}});

scheduledへ0.65秒後の処理を保存します。予告を消してからビームを生成するため、プレイヤーはマーカーが消える瞬間を攻撃開始の合図にできます。

衝突、残機、再開

if (!bullet.opacity || hitCooldown > 0) continue;
const distance = Math.hypot(player.x - bullet.x, player.y - bullet.y);

透明な弾は無視し、被弾直後の1秒はhitCooldownで連続判定を防ぎます。Math.hypotはx差とy差から直線距離を求めます。

if (distance < (bullet.radius ?? 6) + 8) {
  lives--;
  hitCooldown = 1;

弾の半径とプレイヤーの半径8を足した距離より近ければ衝突です。??はradiusが未設定なら6を使うという意味です。衝突したら残機を1減らします。

if (lives <= 0) {
  gameOver = true;
  player.opacity = 0;

残機が0になるとgameOverをtrueにします。次のフレームの先頭でreturnするため、弾幕とプレイヤーの更新が停止します。

restartButton.opacity = 1;
restartButton.onClick = restart;

ゲームオーバー時だけCanvas中央のボタンを表示します。クリックすると弾、時間、スコア、残機、弾幕番号を初期状態へ戻します。

engine.start();

最後にゲームループを開始します。PlayerのonUpdate、BulletのonUpdate、worldの衝突・表示更新が毎フレーム順番に実行されます。
