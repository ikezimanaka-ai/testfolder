計算クイズ：コードの読み方

ゲームで遊ぶ

このゲームは、毎フレーム動くアクションゲームではなく、問題を出して入力を採点するUIゲームです。下のコード片は実際のcalculator-quiz.jsを、初心者が追いやすい大きさに分けたものです。

1. エンジンと画面を用意する

import { Engine, Display } from "./engine.js";
import { TextObject, ButtonObject } from "./ui-objects.js";

importは別ファイルの機能を読み込みます。Engineはゲームループ、Displayは表示のまとまり、TextObjectは文字、ButtonObjectはクリックできるボタンを表します。

const canvas = document.querySelector("#game");
canvas.tabIndex = 0;

HTMLの#gameというcanvasを探し、tabIndex = 0でキーボードのフォーカス先にします。後でcanvas.focus()を呼べるのはこのためです。

const engine = new Engine(canvas, 60, 800, 450);
const world = engine.newDisplay(new Display("quiz", 800, 450, { background: "#172554" }));

engineは目標60FPS、論理サイズ800×450です。worldというDisplayを登録し、背景色を設定します。EngineはSVG表示をcanvasの親要素に重ね、座標を論理サイズに合わせます。

2. 画面の文字と状態

const question = engine.addObject(world, new TextObject("計算クイズ", { x: 400, y: 62, anchor: "middle", fontSize: 34, color: "#f8fafc" }));
const result = engine.addObject(world, new TextObject("「問題を出す」を押してください", { x: 400, y: 112, anchor: "middle", fontSize: 20, color: "#bfdbfe" }));

questionは問題文、resultは案内や判定結果です。xとyは表示位置、anchor: "middle"は文字の中央をその位置に置く指定です。

const scoreText = engine.addObject(world, new TextObject("スコア: 0 / 0", { x: 400, y: 150, anchor: "middle", fontSize: 18, color: "#86efac" }));
const answerText = engine.addObject(world, new TextObject("", { x: 400, y: 205, anchor: "middle", fontSize: 30, color: "#fef08a" }));

scoreTextは正解数/回答数、answerTextは入力中の文字を表示します。TextObjectのtextを書き換えると次のフレームで表示も変わります。

let answer = 0, score = 0, count = 0;
let hasQuestion = false, typed = "";

answerは現在の正解、scoreは正解数、countは採点した回数です。hasQuestionは出題済みか、typedは入力文字列です。letなのでプレイ中に変化します。

3. 問題を出す

function updateAnswer() {
  answerText.text = typed || "答えを入力";
}

関数は処理を名前にまとめたものです。typedが空文字なら右辺の「答えを入力」を使い、空でなければ入力内容を表示します（||は左側が空のとき右側を使います）。

function newQuestion() {
  const a = 2 + Math.floor(Math.random() * 9);
  const b = 2 + Math.floor(Math.random() * 9);

newQuestionは問題を初期化する関数です。Math.random()は0以上1未満、Math.floorは小数を切り捨てるので、aとbは2〜10の整数になります。

answer = a + b; question.text = `${a} + ${b} = ?`;
hasQuestion = true; typed = ""; result.text = "数字キーまたはキーパッドで入力";

足し算の結果を正解として保存し、テンプレートリテラルで問題文を作ります。出題済みをtrueにし、前の入力を空にして案内を更新します。

updateAnswer();
canvas.focus();

入力表示を空の状態に戻し、canvasへフォーカスを戻します。問題を出すボタンをクリックした後も数字キーを受け取れるようにする処理です。

4. 採点と無効な入力

function submitAnswer() {
  if (!hasQuestion) return;

submitAnswerは回答を採点します。問題がまだないときはreturnで関数を即終了します。これは「問題を出す」前の誤操作を無視するガードです。

if (!typed.trim() || Number.isNaN(Number(typed))) {
  result.text = "数字を入力してください"; return;
}

trim()で空白を除き、空入力または数値に変換できない入力を拒否します。キーボードから入るのは数字、-、Backspaceだけなので通常は数値ですが、チェックを置いて安全にしています。

const ok = Number(typed) === answer;
score += ok ? 1 : 0; count++; hasQuestion = false;

Number(typed)を数値にして正解と厳密比較します。正しければ条件演算子で1を加え、countは正誤に関係なく1増えます。採点後は同じ問題を再送信できないようにします。

result.text = ok ? "せいかい！" : `ざんねん、正解は ${answer}`;
scoreText.text = `スコア: ${score} / ${count}`;

正誤に応じた文章とスコアを表示します。正解を当てる、または間違えるたびに表示だけが更新されます。

typed = ""; updateAnswer();
canvas.focus();

採点後は入力欄を空にし、次の問題を待つ状態へ戻します。このゲームには別のゲームオーバーはなく、問題を出すたびに何度でも続けられます。

5. ボタン配列とクリックイベント

const newButton = engine.addObject(world, new ButtonObject("問題を出す", { x: 105, y: 350, width: 190, onClick: newQuestion }));
const submitButton = engine.addObject(world, new ButtonObject("答える", { x: 505, y: 350, width: 190, onClick: submitAnswer }));

2つのボタンをworldへ追加します。onClickに関数を渡すと、ButtonObjectのpointerupイベントでその関数が呼ばれます。ここでは引数を渡さず関数そのものを渡しています。

const keys = ["1", "2", "3", "4", "5", "6", "7", "8", "9", "0", "−", "消す"];
keys.forEach((label, i) => {

keysはキーパッドのラベル配列です。forEachは各要素を順番に処理し、labelは文字、iは0から始まる添字です。

x: 205 + (i % 6) * 66,
y: 245 + Math.floor(i / 6) * 48, width: 58, height: 38,

i % 6で列（0〜5）、Math.floor(i / 6)で行（0〜1）を作り、12個を6列2行に並べます。これは配列のデータから画面のボタンを繰り返し生成する例です。

onClick: () => {
  if (label === "消す") typed = typed.slice(0, -1);

クリック時のアロー関数です。「消す」はslice(0, -1)で最後の1文字を除きます。labelは各反復で異なる値を保持します。

else if (label === "−") { if (!typed) typed = "-"; }
else if (typed.length < 8) typed += label;

マイナスは入力が空のときだけ追加します。それ以外の数字は長さ8未満のときだけ末尾に連結します。表示上の「−」を、数値として使える半角-に変えている点にも注意します。

updateAnswer(); canvas.focus();
},

どのキーパッドボタンでも表示を更新し、次のキー入力のためにcanvasへフォーカスします。

6. キーボードイベントと開始

canvas.addEventListener("keydown", (event) => {
  if (/^[0-9]$/.test(event.key) && typed.length < 8) typed += event.key;

keydownはキーを押したイベントです。正規表現で1桁の数字だけを通し、最大8文字までevent.keyを追加します。

else if (event.key === "-" && !typed) typed = "-";
else if (event.key === "Backspace") typed = typed.slice(0, -1);

空のときだけマイナスを許可し、Backspaceでは最後の文字を消します。

else if (event.key === "Enter") submitAnswer();
else if (event.key === " ") newQuestion(); else return;

Enterは採点、Spaceは新しい問題です。対象外のキーではreturnするので、次の処理を実行しません。

event.preventDefault(); updateAnswer();
}); engine.start();

対応したキーのブラウザ既定動作を止め、入力表示を更新します。最後のengine.start()でEngineのフレーム更新を開始します。このゲームでは毎フレームの独自処理はなく、ボタンやキーイベントが状態と文字を変更します。
