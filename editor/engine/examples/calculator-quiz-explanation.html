計算クイズ：コードの読み方

ゲームで遊ぶゲーム一覧エンジンホーム

このゲームは「問題を出す」「入力する」「答える」の3つだけで成立しています。大事なのは、answer・typed・activeの3つの状態を管理している点です。

1. 画面と表示を作る

import { Engine, Display } from "../engine.js";
import { TextObject, ButtonObject } from "../ui-objects.js";

const canvas = document.querySelector("#game");
const engine = new Engine(canvas, 60, 800, 450);
const world = engine.newDisplay(new Display("quiz", 800, 450, { background: "#172554" }));

const question = engine.addObject(world, new TextObject("問題を出すを押してください", {
  x: 400, y: 100, anchor: "middle", fontSize: 36, color: "#f8fafc"
}));
const answerView = engine.addObject(world, new TextObject("入力: ", {
  x: 400, y: 180, anchor: "middle", fontSize: 30, color: "#bae6fd"
}));

Engineは更新ループ、Displayは描画面を作ります。TextObjectは文字の見た目を持つObjectで、textを書き換えると表示が変わります。

2. 出題と採点の状態

let answer = 0;
let typed = "";
let score = 0;
let count = 0;
let active = false;

function newQuestion() {
  const a = 2 + Math.floor(Math.random() * 9);
  const b = 2 + Math.floor(Math.random() * 9);
  answer = a + b;
  typed = "";
  active = true;
  question.text = `${a} + ${b} = ?`;
  result.text = "数字・-・.を入力して「答える」";
  canvas.focus();
}

newQuestionではつぎの問題を作ります。Math.random()で0〜1の乱数を作り、Math.floorで整数にして2〜10の範囲にしています。

function submitAnswer() {
  if (!active) return;
  if (typed.trim() === "" || Number.isNaN(Number(typed))) {
    result.text = "数字を入力してください";
    return;
  }

  const correct = Number(typed) === answer;
  score += correct ? 1 : 0;
  count++;
  active = false;
  result.text = correct ? "せいかい！" : `ざんねん。正解は ${answer}`;
  scoreView.text = `スコア: ${score} / ${count}`;
}

入力した文字をNumber()で数値に変換し、正解と照合します。activeがfalseなら、問題が出ていないときに勝手に採点しないようにしています。

3. キーボード入力で文字を増やす

canvas.addEventListener("keydown", (event) => {
  if (event.key === "Backspace") typed = typed.slice(0, -1);
  else if (/^[0-9.-]$/.test(event.key)) typed += event.key;
  else if (event.key === "Enter") submitAnswer();
  else if (!["Tab", "ArrowLeft", "ArrowRight"].includes(event.key)) event.preventDefault();
});

newButton.onClick = newQuestion;
submitButton.onClick = submitAnswer;
world.onUpdate = () => { answerView.text = `入力: ${typed || "_"}`; };

入力文字列はtypedに保存され、毎フレームanswerView.textとして画面に出します。大事なのは、ボタンのクリックとキー入力を別のイベントとして扱っていることです。

このゲームの本質は「答えに使う状態を増やしすぎないこと」です。入力値・正解値・現在の問題の有無だけを持てば、十分に動きます。
