ミニシューター：コードの読み方

ゲームで遊ぶ

矢印キーで船を動かし、Spaceを長押しして右向きに弾を連射します。敵は右端から左へ速く進みます。

エンジンとSVG形状

import { Engine, Display, GameObject, INPUT } from "./engine.js";
import { TextObject, BarObject, ButtonObject } from "./ui-objects.js";

Engineはフレーム処理、Displayはゲーム面、GameObjectは動く物、INPUTはキー状態です。文字、体力バー、再スタートボタンもUI Objectとして読み込みます。

const NS = "http://www.w3.org/2000/svg";
const shape = (name, attrs) => {

SVG要素を作るための名前空間をNSに保存し、shape関数を用意します。nameはpolygonやcircle、attrsは属性のオブジェクトです。

const node = document.createElementNS(NS, name);
for (const [key, value] of Object.entries(attrs)) node.setAttribute(key, value);

Object.entriesで属性をキーと値の組に分解し、SVGノードへ設定して返します。

船・弾・敵のクラス

class Ship extends GameObject {
  constructor(overrides = {}) {

ShipはGameObjectを継承した船です。overridesは位置などを呼び出し側から上書きするオブジェクトで、既定値は空です。

super({ tags: ["ship"], shapes: [shape("polygon", { points: "0,-16 22,16 0,9 -22,16" })] }, overrides);
}

superで親を初期化し、タグshipと4点のpolygon形状を渡します。Engineはこの形状をSVGのg内に置き、x,yへ移動します。

onUpdate(dt) {
  if (INPUT.onKey("ArrowLeft")) this.moveX(-260 * dt);

onUpdateはDisplayが毎フレーム呼ぶメソッドです。onKeyは押している間true、dtは前フレームからの秒数なので、速度を時間に掛けて移動します。

if (INPUT.onKey("ArrowRight")) this.moveX(260 * dt);
if (INPUT.onKey("ArrowUp")) this.moveY(-260 * dt);

右はXを増やし、上はSVG座標のYを減らします。船のpolygonは先端が右を向く形です。

if (INPUT.onKey("ArrowDown")) this.moveY(260 * dt);
this.x = Math.max(25, Math.min(775, this.x));

下はYを増やし、Xを25〜775に制限します。Math.minとMath.maxの組み合わせで画面外へ出ません。

this.y = Math.max(55, Math.min(425, this.y));
}}

Yも55〜425に制限します。船のonUpdateには衝突処理を置かず、後でworld全体がまとめて判定します。

class Shot extends GameObject {
  constructor(overrides = {}) { super({ tags: ["shot"], shapes: [shape("rect", { x: -3, y: -10, width: 6, height: 20, rx: 3 })] }, overrides); }

Shotは縦長のrectです。形状のx/yが中心からの相対位置なので、発射位置を弾の中心として描けます。

onUpdate(dt) {
  this.moveX(560 * dt);
  if (this.x > 820) this.opacity = 0;

弾は毎フレーム右へ進み、画面右端より外れたら透明になります。

super({ tags: ["enemy"], shapes: [shape("circle", { r: 18 })],
  hp: 6, maxHp: 6, speed: 230, hitCooldown: 0 }, overrides);

敵は円、体力hpと最大体力maxHp、左へ進む速度speedを持ちます。6発で倒せます。

this.moveX(-this.speed * dt);
this.hitCooldown = Math.max(0, this.hitCooldown - dt);

敵は毎フレーム左へ移動し、接触待ち時間を0まで減らします。

if (this.x < -40) this.reset();
reset() { this.x = 840 + Math.random() * 180; this.y = 70 + Math.random() * 320; }

画面左へ出た敵は、画面右外から再出現します。Yだけランダムに変えます。

this.hp = this.maxHp; this.opacity = 1;
this.hitCooldown = 0;

リセット時に体力、透明度、接触待ちも初期化するため、倒した敵も再出現できます。

初期化、配列、UI

const engine = new Engine(document.querySelector("#game"), 60, 800, 450);
const world = engine.newDisplay(new Display("space", 800, 450, { background: "#020617" }));

canvasからEngineを作り、800×450のspace面を登録します。

const ship = engine.addObject(world, new Ship({ x: 400, y: 390 }));
ship.element.setAttribute("fill", "#67e8f9");

船を中央下へ追加し、作成済みSVG要素の塗り色を設定します。

const enemies = [];
for (let i = 0; i < 6; i++) {

enemies配列に6体を保存します。iは0〜5で、同じ初期化をforで繰り返します。

const enemy = engine.addObject(world, new Enemy({ x: 70 + i * 130, y: 55 + (i % 2) * 70 }));
enemy.hpBar = engine.addObject(world, new BarObject({ x: enemy.x - 22, y: enemy.y + 25, width: 44, height: 6, value: 1, fill: "#ef4444", background: "#450a0a", radius: 2 }));

敵を横に並べ、i % 2で2段にします。各敵に体力バーを追加し、敵自身のプロパティhpBarへ参照を保存します。

enemies.push(enemy);
} const shots = [];

pushで敵を配列へ追加します。shotsも発射した弾を保持する配列で、透明化した弾も残ります。

let score = 0, lives = 3, cooldown = 0;
let gameOver = false; let restartButton;

scoreは撃破数、livesは残りミス、cooldownは連射間隔、gameOverは終了状態です。

再スタートとフレーム更新

function restart() {
  score = 0; lives = 3; gameOver = false; ship.opacity = 1;

再スタートは数値と終了状態を初期化し、船を表示します。

ship.moveTo(100, 225);
for (const enemy of enemies) enemy.reset();

船を開始位置へ戻し、敵配列をfor...ofで全員リセットします。

for (const shot of shots) shot.opacity = 0;
restartButton.opacity = 0; setStatus("撃破: 0　（矢印キー + Space）");

残っている弾を透明にし、再スタートボタンを隠します。配列を空にするのではなく再利用可能な状態にしています。

world.onUpdate = (dt) => {
  if (gameOver) return; cooldown -= dt;

Displayの更新関数は毎フレーム実行されます。ゲームオーバーなら全処理を止め、そうでなければ連射待ちを減らします。

if (INPUT.onKey("Space") && cooldown <= 0) {
  const shot = engine.addObject(world, new Shot({ x: ship.x + 25, y: ship.y }));

onKeyは押している間ずっとtrueです。短い待ち時間を使うので、Space長押しで連射になります。

shots.push(shot); cooldown = .18;
}

弾を配列へ保存し、次の発射まで0.18秒待ちます。

for (const enemy of enemies) {
  enemy.hpBar.moveTo(enemy.x - 22, enemy.y + 25);

毎フレーム敵ごとに体力バーを敵へ追従させます。

enemy.hpBar.value = enemy.hp / enemy.maxHp;
if (enemy.hp <= 0) enemy.reset();

体力割合をバーへ渡し、0以下なら倒した敵を即リセットします。

if (enemy.opacity && Math.hypot(ship.x - enemy.x, ship.y - enemy.y) < 30 && enemy.hitCooldown <= 0) {
  enemy.hitCooldown = 1; lives--;

透明でない敵との距離が30未満なら船との接触です。Math.hypotはX/Y差から距離を求め、1秒の待ちを設定してミスを1減らします。

ship.x = 400; ship.y = 390;
if (lives <= 0) { gameOver = true; ship.opacity = 0; }

接触後は船を開始位置へ戻します。残りミスが0ならゲームオーバー状態にし、船を隠します。

restartButton.opacity = 1;
setStatus(`ゲームオーバー　スコア: ${score}`); }

再スタートボタンを表示し、最終スコアを表示します。ボタンのクリックイベントは後でrestartButton.onClick = restartとして接続されています。

for (const shot of shots) {
  if (!shot.opacity) continue;

透明な弾はcontinueで飛ばします。表示中の弾だけ敵との衝突を調べます。

if (enemy.opacity && Math.hypot(shot.x - enemy.x, shot.y - enemy.y) < 25) {
  shot.opacity = 0; enemy.hp--; if (enemy.hp <= 0) score++;

表示中の敵との距離が25未満なら命中です。弾を消し、体力を1減らし、0以下になった瞬間だけ撃破数を増やします。

setStatus(`撃破: ${score}　（矢印キー + Space）`);
livesText.text = `残りミス: ${lives}`;

各フレームの最後にステータスと残りミスを更新します。最後にengine.start()がrequestAnimationFrameのループを開始し、各ObjectのonUpdateとworldの更新を繰り返します。
