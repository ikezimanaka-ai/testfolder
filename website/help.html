01 Object

ゲーム内の物体です。テンプレートをEngineへ登録し、DisplayにIDで複製を追加します。Programs内では self が現在のObjectです。

initialPrograms はDisplay追加時に1回、programs は毎フレーム実行します。self.copy() で生まれたObjectだけ self.isCopy が true になります。addObjectById() で追加したObjectはfalseです。

getInfo()

Objectの設定をコピー可能な情報として返す。

copy(overrides)

Objectを複製する。指定した設定だけ上書きできる。

setId(id)

IDを変更する。使用中のIDならエラー。

setPrivate(name, value)

このObject専用の値を保存する。他のObjectから直接参照できない。

getPrivate(name, fallback)

このObject専用の値を取得する。未設定ならfallbackを返す。

hasPrivate(name)

このObject専用の値が設定されているか調べる。

move(dx, dy)

xとyを相対移動する。角度は変わらない。

Xmove(distance)

右方向へ移動する。xに距離を足し、角度は変えない。

Ymove(distance)

上方向へ移動する。Canvas座標のyから距離を引き、角度は変えない。

moveTo(x, y)

中心座標を指定位置へ移動する。

rotateTo(angle)

角度を指定値へ変更する。単位は度。

rotateBy(degrees)

現在の角度へ指定角度を加える。

containsPoint(x, y)

複合コライダーのいずれかに点が含まれるか調べる。

intersectsObject(other)

矩形・円・多角形の複合コライダーが交差するか調べる。

touchesTag(tag, display)

指定タグを持つObjectに触れているか調べる。

touchesColor(color, tolerance, display)

指定色のObjectに触れているか調べる。R/G/Bすべてが許容差以内なら一致。

isColorWithinTolerance(color, tolerance)

自分の色が指定RGB色から許容差以内か調べる。

setImage(image) / loadImage(url)

Image要素やURL画像をObjectへ設定して描画する。

touchesDisplayEdge(display)

Displayの端に触れているか調べる。

remove()

所属中のDisplayから自分を削除する。

removeFrom(display)

指定Displayから削除する。省略時は所属Displayを使う。

02 Display

Objectを描画するレイヤーです。EngineコードではDisplay名を変数として使えます。

listObjects()

所属Objectの配列コピーを返す。

findByTag(tag)

指定タグを持つObjectを返す。

findByCondition(fn)

条件関数に一致するObjectを返す。

addObject(object)

Objectを直接追加する。

addObject(id, overrides)

テンプレートIDから複製して追加する。

addObjectById(id, overrides)

テンプレートIDから複製して追加する。

addObjectFromPrototype(proto, overrides)

プロトタイプから複製して追加する。

addDrawable(fn)

Canvasへ独自描画する関数を登録する。

pauseAll() / resumeAll()

Displayの一時停止フラグを切り替える。

hideObject(id) / showObject(id)

IDのObjectを一時的に非表示・再表示する。

delete()

EngineからDisplayを削除する。

03 Engine

ゲームループ、Display、テンプレート、起動コードを管理します。

createDisplay(spec)

Displayを作成してEngineへ追加する。

addDisplay(display)

既存DisplayをEngineへ追加する。

registerTemplate(object)

ObjectをID付きテンプレートとして登録する。

getTemplate(id)

IDからテンプレートを取得する。

unregisterTemplate(id)

テンプレート登録を解除する。

addStartupProgram(source)

開始時に実行するコードを登録する。

runStartupPrograms()

登録済みの開始時コードを実行する。

onUpdate(fn)

毎フレームの更新関数を登録する。dtは秒単位。

removeUpdate(fn)

更新関数の登録を解除する。

onRender(fn)

Canvas描画後に呼ぶ関数を登録する。

start() / stop()

ゲームループを開始・停止する。

04 Input

Programsでは INPUT を使います。Engine内部では engine.input から詳細APIにもアクセスできます。

INPUT.mouse()

x、y、pressed、justClicked、lastClickTimeを返す。

INPUT.key(key)

指定キーが押されている間trueを返す。

isKeyPressed(key)

InputManagerでキー状態を調べる。

timeSinceLastClick()

最後のクリックからの経過時間をmsで返す。

attachTo(element)

マウス・キーボード入力の対象を設定する。

detach()

入力イベントの監視を解除する。

update()

フレーム単位のjustClickedをリセットする。

const mouse = INPUT.mouse();
if (INPUT.key('ArrowRight')) self.Xmove(120 * dt);
if (mouse.justClicked) self.moveTo(mouse.x, mouse.y);

05 Utils

座標・距離・角度計算のための静的ヘルパーです。Programsでは GameEngine.Utils から使えます。

distancePoints(ax, ay, bx, by)

2点間の距離を返す。

distancePointToObject(px, py, object)

点からObject中心までの距離を返す。

distanceObjectToObject(a, b)

2つのObject中心間の距離を返す。

angleToDxDy(angle, distance)

角度と距離をdx, dyへ変換する。

Canvasの座標は左上が原点です。そのため Xmove(10) は右へ、Ymove(10) は上へ10移動します。
