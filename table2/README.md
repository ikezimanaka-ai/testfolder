# TABLE 2

`table2/` は `table/` と独立した共有テーブルです。既存のカード、コイン、画像、描画、チャット機能に加えて、ゲーム進行と麻雀牌を使えます。

## 起動

リポジトリのルートで静的HTTPサーバーを起動し、`/table2/` を開きます。

```sh
python3 -m http.server 8000
```

SkyWay接続には [app.js](./app.js) 冒頭の `API_KEY` と `PASSWORD` をローカルで設定します。秘密鍵を含む状態で公開しないでください。本番運用では秘密鍵をブラウザーへ置かず、サーバーから短期トークンを発行してください。

## ゲーム

- 大富豪は [`millionaire/beta/README.md`](../millionaire/beta/README.md) のルール・カード効果を使います。最大10人で、手札のカードを選んで出す／パスする操作は手番の人だけ行えます。
- 神経衰弱は同じ数字・柄の2枚をペアとして扱います。ペアがそろうと同じ人が続け、外れたら「次の人へ」で手番を進めます。
- ババ抜きはジョーカー1枚を含むカードを配り、次の人の手札から1枚引きます。同じ数字2枚は自動で捨てられ、最後にジョーカーを持つ人が負けです。
- 対戦中に入室した人は観戦者です。そのゲームが終わると、次のゲームから参加できます。ホストは途中でゲームを終了できます。
- 所持コインから賭け金を共通ポットへ預けられます。ゲーム終了後、ホストが勝者へ渡すか、預けた人へ返金できます。次のゲームを始める前に精算してください。
- 麻雀牌は標準136枚（赤牌3枚を通常の5と置換）です。牌山から引き、自分の手牌から場へ出せます。役・和了・手番の自動判定はありません。牌画像は既存の `../pai-images/pai-images/` を参照します。

## テスト

リポジトリルートで次を実行します。

