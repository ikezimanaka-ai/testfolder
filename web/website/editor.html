Object Templates

機能ガイド

Template
Object一覧はテンプレートです。Engine startup codeでDisplayを作り、main.addObjectById('id') で実体を追加します。

Programs
self.move()、self.remove()、self.removeFrom(display) が使えます。

入力
INPUT.mouse() は座標・押下状態を返し、INPUT.key('ArrowLeft') はキー状態を返します。

操作
Start / Stop / Resetで実行を制御します。Debugを有効にするとCanvas更新ごとにObjectの変数を表示します。

画像と当たり判定
矩形・円・PNG/JPEG・CSV多角形に対応し、複数コライダーのどれかが交差すれば衝突です。
